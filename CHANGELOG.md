# 📝 Changelog

All notable changes to ExpenseAI will be documented in this file.

## [1.0.0] - 2026-08-15

### Added
- 🎉 Initial release of ExpenseAI (Final Version)
- 🔐 JWT Authentication with HttpOnly cookies & refresh token
- 💰 Transaction CRUD operations
- 🤖 AI-powered transaction classification (OpenAI GPT-4o-mini)
- 🧠 AI financial advice and recommendations
- 📊 Interactive dashboard with Chart.js
- 🔍 Search and filter transactions
- 📅 Filter transactions by date range
- 🐳 Docker containerization & Alembic DB Migrations
- 📝 Comprehensive API documentation (Swagger UI)
- 🧪 Unit and integration tests with Pytest
- 🚀 CI/CD pipeline with GitHub Actions readiness

### Security
- 🔒 Password hashing with bcrypt
- 🛡️ Rate limiting on auth endpoints (SlowAPI)
- 🚫 SQL Injection prevention (SQLAlchemy)
- 🔑 Environment variables for sensitive data (`.env`)

## [0.9.0] - 2026-07-20

- Initial project structure
